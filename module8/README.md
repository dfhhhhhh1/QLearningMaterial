# Module 8: Current Research and Future Planning

The final module steps back from the tooling and looks at where the field is going and where you fit in it. Different hardware modalities make different bets; the logical-vs-physical qubit gap sets the timeline; and the question of which fields see value first is still genuinely open. The capstone is a quantum project plan for a problem you actually care about.

Start with [Schedule.ipynb](Schedule.ipynb) -- it is the entry point for this module and links
everything below in the order you should work through it.

## Folder Layout

| Folder | Contents |
|--------|----------|
| `labs/` | Walk-through notebooks. Read and run these; they are not graded. |
| `practices/` | Ungraded hands-on notebooks with answers provided in `answers/`. |
| `exercises/` | Graded assignments. Commit and push your completed work. |
| `answers/` | Answer keys for the practices and exercises that have them. |
| `resources/` | Slide decks, PDFs, and reference material. |
| `images/` | Figures used by the notebooks in this module. |
